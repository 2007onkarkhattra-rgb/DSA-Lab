1. Bubble Sort
Aim
To write a C++ program to sort an array of elements in ascending order using the Bubble Sort algorithm.

Algorithm
Start.
Declare and initialize an array.
Find the number of elements in the array.
Compare adjacent elements of the array.
If the first element is greater than the second element, swap them.
Repeat the comparison for all adjacent elements.
Repeat the above process for n-1 passes.
Display the sorted array.
Stop.
Steps / Procedure
Initialize the array as {5, 3, 8, 4, 2}.
Set n = 5.
Use an outer loop from i = 0 to n-2.
Use an inner loop from j = 0 to n-i-2.
Compare arr[j] with arr[j+1].
If arr[j] > arr[j+1], swap the two elements.
Continue until all elements are arranged in ascending order.
Print the sorted array.
The final output is 2 3 4 5 8.
